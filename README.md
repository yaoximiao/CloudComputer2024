# 项目说明文档

## 一、项目背景

随着现代教育信息化程度的提升，大学生在日常学习和复习过程中面临着大量的信息和资料。如何快速、精准地获取所需知识，并在浩瀚的知识海洋中高效航行，成为大学生的一大挑战。传统的学习方式往往缺乏个性化与精准性，而现有的问答系统多为宽泛性的回答，无法根据特定学科领域的知识提供深度、精确的解决方案。因此，如何为大学生设计一个基于现代技术的智能学习辅助工具，成为亟待解决的问题。

本项目旨在利用**Langchain**大模型的强大能力和**云计算**的计算资源，设计一个智能问答系统——**LearnSailor**，帮助大学生在学习过程中高效、精准地定位和获取所需信息。通过将上传的学习资料构建成**本地知识图谱**，系统能够提供像智能导航一样的精准指引，帮助学生在学术知识的学习和复习过程中，快速解决疑惑并提升学习效率。



## 二、市场分析

| **对比维度**   | LearnSailor                                                  | **现有教育问答系统**                                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **知识更新**   | 通过构建本地知识图谱，能快速整合上传资料中的知识             | 知识无法根据具体领域的资料进行更新，难以给出精准的回答       |
| **理解能力**   | 基于Langchain大模型，具备强大的自然语言理解能力，能准确理解学生复杂的提问和多样的表达方式 | 理解能力有限，常因学生表达不清晰或问题复杂而无法准确理解，导致回答偏差 |
| **个性化程度** | 能根据学生上传的不同资料信息，提供个性化的答疑服务           | 个性化服务不足，多为通用型回答，难以满足不同学生的学习需求和偏好 |
| **知识关联性** | 利用知识图谱技术，能挖掘知识之间的关联关系，为学生提供系统化、结构化的知识学习路径 | 知识关联性弱，常孤立地回答问题，缺乏对知识体系的全面展示和引导 |
| **交互体验**   | 采用交互式对话界面，回答精确简洁，赏心悦目                   | 交互体验较差，回答过于冗长                                   |

### 提出方案

**1. 精准的知识检索与答疑服务**

利用**Langchain**大模型和图数据库技术，构建智能知识图谱，提供精准的知识检索和答疑服务。学生可以通过交互式问答，快速获得与学科相关的具体问题的解答，避免传统学习方式中的低效和泛化。

**2. 知识图谱的可视化与理解**

 通过采用**Neo4j**图数据库技术，构建和展示学科知识点之间的关联关系，学生可以更加直观地理解不同知识点之间的联系和内在逻辑，从而提升对知识的深度掌握与灵活运用。

**3. 个性化学习指导**

系统通过不断优化模型和数据分析，为学生提供个性化的学习建议和方向指导，帮助学生根据自己的学习进度和需求，选择合适的学习内容和复习方法。




## 三、设计思路

- ![](/项目架构图.png)

- **整体架构**：
  
  - **前端界面**：前端支持智能问答、图问引擎
  - **后端服务**：问答系统（基于Langchain大模型）、知识库管理（存储、更新、检索知识）、知识图谱构建（从上传文件生成graph进行存储）
  - **云计算平台**：采用 Openai 以及 DeepSeek 的 API，同时使用Neo4j图数据库
  
- **组件协同工作**：
  
  - 用户前端提问或浏览知识库，请求传至后端服务
  
  - 问答引擎用Langchain大模型语义理解、匹配问题，从知识库检索知识，结合知识图谱生成答案
  
  - 知识库管理模块存储、更新知识数据，支持分类、标签化检索
  
  - 知识图谱构建模块从上传资料提取信息，构建本地知识图谱，丰富知识库内容
  
    

## 四、技术实现

- **技术栈**：
  - **前端技术**：使用HTML、CSS、JavaScript、Vue.js，开发用户交互界面
  - **后端技术**：基于Python、Flask，使用Langchain框架，开发后端服务
  - **知识图谱技术**：采用Neo4j图数据库，将资料转化成graph，构建和管理本地知识图谱
  
- **Langchain和云服务的利用**：
  - Langchain大模型语义理解、匹配问题，从知识库准确检索知识，结合知识图谱生成高质量答案
  
  - 云graph数据库存储知识图数据，确保数据安全，同时获得专业的图数据库管理和优化支持
  
  - 将项目封装成docker，采用docker实现自动部署

## 六、创新点

- **高效的知识检索**：利用neo4j构建本地知识图谱，利用graph结构高效检索知识点，为大学生提供更加精准和高效化的学习支持

- **深度个性化服务**：结合Langchain大模型和知识图谱技术，大学生能管理和生成包含多学科的个性化知识库，同时满足大学生的不同学习需求

- **多维度知识关联展示**：利用知识图谱挖掘知识之间的关联关系，便于大学生整理多门学科的知识，帮助构建完整的知识体系，提升学习的深度和广度

- **智能交互与反馈**：采用交互式对话界面，大学生可上传相应资料与系统进行多轮互动，增强学习的互动性和灵活性，复习知识时采用对话形式也不会太枯燥


### 后端

1. 进入后端目录，在此前请确保您安装了Ollama工具
   ```
   cd backend
   ```

2. 安装依赖：
   ```
   pip install -r requirements.txt
   ```

3. 运行后端应用：
   ```
   python src/app.py
   ```

### 前端

1. 进入前端目录，在此前请确保您安装了Vue.js
   ```
   cd frontend
   ```

2. 安装依赖：
   ```
   npm install
   ```

3. 运行前端应用：
   ```powershell
   npm run serve
   ```

### Docker部署

本项目还采用Docker技术对项目进行封装，支持一键部署。

#### 使用说明

- 前端应用提供了一个用户界面，用户可以输入查询并与知识库代理进行交互。
- 后端应用处理来自前端的请求，并使用LangChain进行知识库查询。

前端和后端以镜像形式部署在了GitHub Container Registry，访问yaoximiao成员的Packages可以获取(已处于Public)。

拉取后端

```plain
docker pull ghcr.io/myusername/chatnote_backend:latest
```

拉取前端

```plain
docker pull ghcr.io/myusername/chatnote_frontend:latest
```

且在github的仓库的docker分支中yaoximiao分享了docker-compose.yml, （推荐）可以使用它一键启动项目，只需运行以下代码

```plain
docker-compose up
```
